## Project summary

Voice-driven NYC 311 complaint filing. Speak a complaint → Gemini STT transcribes →
Pinecone (integrated inference + rerank) returns top-5 311 service matches → LLM
(Gemini or SLM) picks best match → fills form → **mock** submit to NYC 311
`CreateServiceRequest`. Runs on a Mac host; iPhone is a thin browser client over Tailscale.

**Plan:** `PLAN.md` (approved). Approach A (safe vertical slice) + SLM-vs-Gemini bake-off.
TDD. Build test-first.

## Key facts / decisions

- Vector DB: Pinecone, integrated inference + rerank. Embedding `llama-text-embed-v2`
  (1024-dim), rerank `bge-reranker-v2-m3`, index `311-voice`, namespace `nyc-311`.
- Rerank returns top-5 (not top-3) for the agent to reason over.
- Jurisdiction: NYC. NYC 311 API is custom (NOT Open311). Key in `API.md` (gitignored).
- Submission is MOCKED — never POST a real service request.
- STT: Gemini audio (multimodal), NOT whisper.cpp. Browser records audio → backend → Gemini.
- LLM: A/B bake-off. Gemini (gemini-3.1-flash-lite) vs SLM (llama.cpp + Qwen3.5-2B-UD-IQ2_M.gguf).
- Frozen API contract (§6 of PLAN.md):
  - `GET /api/health` → `{ok, llm_backend}`
  - `POST /api/match` → `{candidates[5], picked_ka, reasoning, extracted_fields}`
  - `POST /api/submit` → `{sr_number, payload, status: "mock-submitted"}`
  - `POST /api/copilotkit` → CopilotKit runtime
