## Project summary

Voice-driven NYC 311 complaint filing. Speak a complaint → whisper.cpp transcribes →
Pinecone (integrated inference + rerank) returns top-5 311 service matches → LangChain
agent reasons + picks → maps to NYC `{agency, problem, problemDetails, locationType}` →
fills a fixed-schema (A2UI) form → **mock** submit to NYC 311 `CreateServiceRequest`.
Runs on a Mac host; iPhone is a thin browser client over Tailscale. (Vector DB is
Pinecone cloud, so retrieval is NOT local — STT + SLM + orchestration are.)

## Key facts / decisions

- Vector DB: Pinecone, integrated inference + rerank. Embedding `llama-text-embed-v2`
  (1024-dim), rerank `bge-reranker-v2-m3`, index `311-voice`, namespace `nyc-311`.
- Rerank returns top-5 (not top-3) for the agent to reason over.
- Jurisdiction: NYC. NYC 311 API is custom (NOT Open311). Key in `API.md` (gitignored).
- Submission is MOCKED — never POST a real service request.
- SLM: `unsloth/Qwen3.5-2B-MTP-GGUF` file `Qwen3.5-2B-UD-IQ2_M.gguf` (<1GB) via llama.cpp.
- STT: whisper.cpp base model (on the Mac, not whisper.rn).
